# Business Observability: 20-Article SEO Agent Handoff

**Campaign:** 20 proposed keywords; 2 approved articles per publishing day across 10 days. **Date compiled:** 13 November 2026.

> Important: No keyword-volume, difficulty, CPC or live SERP clustering analysis was available. The 20 terms are editorial candidates, not a validated top-20 by volume. Do not claim otherwise.

## Autonomous writing agent operating instructions

1. Set `SITE_DOMAIN`, audience, product truth source, brand voice, CMS credentials, timezone and publishing start date. Slugs shown below are **planned paths**, not existing live URLs. Discover real on-site links from the sitemap/CMS before publishing; never create a hyperlink to a future page as though it were live.
2. Each day select the next two eligible briefs. First inspect the current search results and existing website sitemap/content. If two terms share the same intent and dominant SERP URLs, recommend a single canonical page and reassign the extra slot; **do not publish near-duplicates just to hit quota**. Highest-risk overlaps: BO-02/04/10/11 and BO-06/09.
3. Research each factual claim from primary authoritative sources. Open all external reference URLs below, verify they still resolve, and check for changed information, date and context. These are seed citations, not pre-approval of every claim. Never invent sources, quotes, statistics, vendors, prices, customers, tests, certifications or performance claims.
4. Draft useful original content: answer primary intent in first 100 words; distinguish the brief from sibling pages; include substantive original synthesis, a process/example, the specified original asset and 3-5 FAQs based on genuine questions. Cite sources in prose via contextual markdown/HTML links alongside factual claims. Use 2-4 well-chosen external citations when support is available, not artificial link quotas.
5. Build 3-5 contextual links to other relevant articles where live, including at least one pillar link to BO-01 for supporting pages where natural. **After BO-01 is published, revisit day-1 BO-02 and other older posts to add reciprocal links to new live pages.** Queue unlive link targets as post-publication update tasks, not broken links. Also add links to verified existing conversion/product pages if genuinely relevant. Anchor text must be descriptive and vary naturally.
6. Produce metadata: SEO title (roughly 50-60 characters where feasible), meta description (roughly 140-160 characters), one H1, useful subheadings, short slug, byline and review date, and image alt text. These are editorial heuristics, not search engine hard limits. Add appropriate structured data only if supported by real content.
7. Before approval perform: URL availability check; claim-source audit; originality checks against all 19 briefs and existing website; accessibility check; link HTTP status check; spellcheck; author/source transparency; brand/legal review where needed; no unsupported claim or fabricated case study. Prioritise quality over output volume.
8. Publish **at most two quality-approved pieces per day**. If direct CMS publication authority is unavailable, output publication-ready Markdown/HTML, metadata and a publication queue; do not claim a post went live. Capture the live canonical URL and verify it resolves, then update the internal-link graph.
9. Log article ID, keyword, canonical URL, publish date, references used, link targets, QA verdict, status, owner and reasons for hold. Run a weekly crawl for orphaned articles and broken links. Monitor Search Console impressions, queries, CTR, indexation, and later conversions; revise based on observed performance, not assumptions.
